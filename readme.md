## Dərs 2: Variables, Data tipləri və Basic syntax

* What are variables?
* Data Tipləri - Numeric (int, float, complex), String (string), Boolean (true, false), Sequence (list, tuple, range), Binary (bytes, bytearray, memoryview), Mapping (dict), Set (set, frozenset)
* Numbers (int, float)
* Strings (text)
* Booleans (True/False)
* Keywords nədir və icazə verilməyən variable adları hansılardır
* Type conversion
* type() funksiyası
* Kommentlər
* Simple input/output with print() and input()

## Dərs 3: String-lər üzərində ilə işləmək

## Dərs 4: Operatorlar
