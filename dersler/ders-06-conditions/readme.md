Mövzular

* Şərt (condition) nədir
* `if elif else` necə istifadə olunur
* Indentation - Məcburi 4 boşluq nədir
* Mürəkkəb şərtlər (nested conditions) - Operatorlardan istifadə
* `in` keyword (Strings, lists)
* Condition scope nədir
* Bir line-da (One line) şərt yazmaq
* match-case nədir və necə yaradılır - `match, case, _**`
