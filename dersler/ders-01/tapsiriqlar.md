# Python Dərs 1: Tapşırıqlar və suallar

## A. Praktik tapşırıqlar

1. Python və Visual Studionu quraşdırın
2. Visual Studioda yeni qovluq acin və yeni python faylı yaradın
3. Terminalı açın və python versiyasına baxın
4. print() funksiyası ilə Adınızı, Soyadınızı, yaşınızı, və xırda hər hansı bir cümlə yazın
5. print() funksiyası ilə hər hansı riyazi əməliyyat edin (toplama və ya çıxma və s.)
6. Kodunuzda kommentlər qeyd edin (məsələn yazılan kodun üstündə kod haqqinda məlumat verin)
7. Kodunuzda bilərəkdən xəta yaradın (məslən print adın düz yazmayın və yaxud mötərizə qoymuyun)

## B. Cavab verməli suallar

1. Proqramlaşdırma dili nədir? Python-un harada istifadə olunduğunu ən azı 3 nümunə ilə deyin.
2. `.py` faylı nə üçün lazımdır?
3. Visual Studio Code nədir və nə üçün lazımdır?
4. Terminal nədir?
5. `print()` nədir?
6. `print("5 + 3")` ilə `print(5 + 3)` arasındakı fərq nədir?
7. Komment nə üçündür?
8. Koda niyə xətalar baş verir
