# Python Dərs 4: Şərtlər (Conditions)

### Tapşırıqlar

1. `yas = 40`. `əgər yas 18-dən böyükdürsə terminalda "Siz böyüksünüz"` yazılsın
2. `eded = 7`. Əgər ədəd 10dən böyükdürsə `"Böyükdür"`, deyilsə `"Kiçikdir"` yazılsın
3. `bal = 75`. əgər bal `90` və yuxarı `"Əla"`, `70` və yuxarı `"Yaxşı"`, `50` və yuxarı `"Kafi"`, qalanı `"Qeyri-kafi"` yazılsın
4. `a = 10`, `b = 20`  müqayisə operatorlarından (`==`, `!=`, `<`, `>`, `<=`, `>=`) istifadə edərək hansı ədədin böyük olduğunu tapın
5. sifre adlı dəyişən yaradın və əgər sifre `"12345678"` -ə bərabərdirsə `"Giriş etdiniz"`, deyilsə `"Parol səhvdir"` yazılsın
6. `yas = 25` və `bilet_var = False`. Əgər yaşımız 18-dən yuxarı və biletimiz varsa terminalda  `"Daxil ola bilərsiniz"`, əks halda `"Giriş qadağandır"` yazılsın
7. `yagis_yagir = False`. `Əgər yağış yağmırsa "Çətir lazım deyil"` yazılsın
8. bool()-dan istifadə edərək 0 və mənfi ədədlərin nə qaytardağına baxın
9. `yas = 20`. **Ternary** ilə cavab olaraq `"böyük"` və ya `"uşaq"` yazılsın
10. `input()` ilə iki ədəd alın və ternary istifadə edərək böyük olanı tapıb `Böyük ədəd ` formasında göstərin.
11. `gun_nomresi = 3` verilib. `match`, `case` ilə həftənin gününü göstərin: `1` → `"Bazar ertəsi"`, `2` → `"Çərşənbə axşamı"`, `3` → `"Çərşənbə"`. Digər hallar üçün düzgün olmayan rəqəm yazılsın
12. `input()` ilə istifadəçidən ədəd alın (`int()` ilə çevirin). `if` və `else` ilə ədədin **cüt** yoxsa **tək** olduğunu göstərin (`%` operatoru ilə).

### Suallar

* Şərt (condition) nədir?
* `if`, `elif` və `else` arasında fərq nədir?
* `=` ilə `==` arasında nə fərq var?
* `elif` neçə dəfə istifadə oluna bilər? `else` məcburidirmi?
* `!=` operatoru nə edir?
* Müqayisə operatorlarının nəticəsi hansı tipdə olur?
* `and` operatoru nədir?
* `or` operatoru nədir?
* `not` operatoru nə edir? `not True` nə qaytarır?
* Hansı dəyərlər falsy sayılır?
* `bool("")` ilə `bool(" ")` fərqi nədir?
* Ternary operator nədir və adi `if-else`-dən nə ilə fərqlənir?
* `match-case` nədir?
* indentation nədir?
