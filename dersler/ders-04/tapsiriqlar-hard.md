# Python Dərs 4: Şərtlər (conditions)

### Tapşırıqlar

1. Üçbucağın tərəflərini yaradın (a, b, c). Üçbucağın tipini tapın: bərabərtərəfli, bərabəryanlı və ya müxtəlifyanlı.
2. `input()` ilə parol alın. Parol dəyişəni yaradın. Aşağıdakı tapşırıqları edin:

* uzunluq ən az 8 olmalıdır,
* boşluq olmamalıdır,
* ən az bir böyük hərf olmalıdır,
* ən az bir kiçik hərf olmalıdır.

3. Match-case ilə kalkluyator hazırlayın. input-dan istifadə edərək terminaldan iki reqem və birdənə operator götürün (`+`, `-`, `*`, `/`, `//`, `%`, `**`). Həmçinin sıfıra bölmək probleminidə həll edin.
4. **Emailin düzgün olub olmadığın yoxluyun**

   * `@` işərəsi olmalıdır və birinci simvol olmamalıdır
   * domain adı mövcuddur (nöqtə varsa yoxluyun)
5. input ilə terminaldan 1-12 arası rəqəm alın və həmin ayın hansı fəsilə düşdüyünü tapın
6. Daş Kağız Qayçı oyunun düzəldin. input ilə iki dənə seçim götürün və qalibi təyin edin
7. ATM düzəldin. `balans = 500` verilib. `input()` ilə əməliyyat seçin: `1` balans, `2` pul çıxarma, `3` pul əlavə, `4` çıxış. Sistemi match ilə düzəldən. Aşağıdakı qaydaları tətbiq edin

   * məbləğ `0`-dan böyük olmalıdır,
   * balansdan çox ola bilməz,
