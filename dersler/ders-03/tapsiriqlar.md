# Python Dərs 3: String ilə işləmə

### Tapşırıqlar

1. `"Salam"` və `"Python"` sətirlərini `+` ilə birləşdirib terminalda göstərin (aralarında boşluq olsun).
2. Adı `şeher` olan dəyişənə `"Bakı"` dəyərini verin və  `"Mən Bakıda yaşayıram"` cümləsini qurub göstərin
3. `ad = "Aysel"` və `yas = 20` dəyişənlərini təyin edin. f-string ilə `Mənim adım Aysel, yaşım 20-dir` cümləsini göstərin.
4. `"""` `"""` istifadə edərək 3 sətirdən ibarət çoxsətirli mətn yazın və terminalda göstərin.
5. `"python proqramlaşdırma"` sətirini `.upper()` ilə böyük hərflərə çevirin.
6. `"PYTHON"` sətirini `.lower()` ilə kiçik hərflərə çevirin.
7. `"yeni dil öyrənirəm"` sətirinə `.title()` və `.capitalize()` tətbiq edib nəticələri müqayisə edin.
8. `"   myemail@gmail.com   "` sətirindəki lazımsız boşluqları `.strip()` ilə silin.
9. `"Mən Java sevirəm"` sətirində `"Java"` sözünü `"Python"` ilə əvəz edin (`.replace()`).
10. `"Azərbaycan"` sözündə `"r"` hərfinin indeksini `.find()` ilə tapın.
11. `"Dünyadakı adaların sayı çoxdur"` cümləsində `"a"` hərfinin neçə dəfə işləndiyini `.count()`
12. `"Proqramlaşdırma"` sözünün uzunluğunu `len()` ilə tapın.
13. `"Proqramlaşdırma"` sözündə `"proqram"` sözünü slicing ilə çıxardın
14. `"Bu byzym 3-cü dərsymyzdyr"` bu cümləni kopyalayın və y-nı i-ilə əvəzləyərək cümləni düzəldin

### Suallar

* String nədir və necə yazılır?
* `+` operatoru string-lərdə nə edir?
* f-string nədir və adi birləşdirmədən nə ilə rahatdır?
* `"""` `"""` nə üçün istifadə olunur?
* `.upper()` və `.lower()` metodları nə edir?
* `.title()` ilə `.capitalize()` arasında fərq nədir?
* `.strip()` metodu nə üçündür?
* `.find()` metodu axtarılan hərfi tapmasa nə qaytarır?
* Python-da indekslər neçədən başlayır?
* `len()` funksiyası nə qaytarır?
