# Python Dərs 2: Variables və Riyazi Operatorlar

## Tapşırıqlar

1. `"150"` dəyərini int tipinə çevirin
2. İki ədədin cəmini, fərqini, hasilini və nisbətini (`+`, `-`, `*`, `/`) hesablayıb nəticələri terminalda göstərin.
3. Adı `şeher` olan bir dəyişən təyin edin və ona string bir dəyər verin.
4. Adı `a`, `b` və `c` olan üç fərqli dəyişənə eyni sətirdə fərqli tam ədədlər təyin edin və hər birini ekranda göstərin.
5. `input()` ilə terminaldan user yaşını götürün
6. `input()` ilə terminaldan iki ədəd götürün və cəmini hesablayıb terminalda göstərin
7. `17` ədədinin `5`-ə bölünməsindən alınan tam hissəni və qalığı tapın
8. `45.99` rəqəmini int tipinə çevirin və nəticəni terminalda göstərin.
9. `2`-nin `8`-ci dərəcədən qüvvətini hesablayın terminalda göstərin (**)
10. Adi bölmə (`/`) ilə tam bölmə (`//`) operatorları arasındakı fərq nədir?
11. `(10 + 5) * 2 - 8 / 4` ifadəsinin nəticəsini terminalda göstərin.
12. Adı `tempratur` olan bir dəyişən yaradın və ona kəsr ədəd təyin edin

## **Suallar**

* Dəyişən (variable) nədir?
* məlumat tipləri (data types)  nədir və hansılar var?
* Dəyişən adlandırarkən hansı qaydalara əməl etməliyik?
* `input()` funksiyası nə üçündür?
* `input()` funksiyası istifadəçidən məlumatı həmişə hansı tipdə götürür?
* `"25"` dəyəri ilə `25` dəyəri arasında nə fərq var?
* `int(45.99)` yazsaq ekranda neçə çıxar və niyə?
* `//` nə üçündür?
* Qüvvətə yüksəltmə üçün hansı operatordan istifadə olunur?
