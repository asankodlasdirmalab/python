
### Dərs 5: List-lər

* List nədir, necə yaradılır, elementlər və indekslər (mənfi indekslər daxil)
* Əlavə etmək: .append(), .insert(), .extend()
* Silmək: .remove(), .pop(), .clear(), del
* Slicing və list-ləri + ilə birləşdirmək
* .copy() və referans problemi (b = a nəyi dəyişir)
* .reverse(), .sort() ilə sorted() fərqi, .index(), .count()
* in və not in - şərtlər
* split() - sözləri listə çevirmək
* len(), min(), max(), sum()
